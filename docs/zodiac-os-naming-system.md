# Zodiac OS Naming System

This document outlines the standard naming conventions for the platform to ensure a coherent product identity.

## Core Naming Rules

*   **Zodiac OS**: The entire Telegram management platform (the full product).
*   **Zodiac Control**: The management dashboard/admin console.
*   **Zodiac Mini**: The user-facing Telegram Mini App.

## Module Names

*   **Zodiac Network**: The Telegram channel network (management and operations of the 15 channels).
*   **Zodiac Publisher**: The publishing center (daily lane, scheduling, dry-run).
*   **Zodiac Studio**: The content/template engine (local-only templates, rubrics).
*   **Zodiac Pulse**: Analytics (Redis metrics, funnels, privacy-safe counters).
*   **Zodiac Voice**: The feedback center (sanitized reviews, P0/P1 triage).
*   **Zodiac Shield**: Security and admin safety (ledger, access control, protection).
*   **Zodiac Mobile**: Future iOS/Android mobile apps.

## Usage Guidelines

*   Use **Zodiac OS** instead of generic terms like "Telegram Platform" or "Zodiac Platform".
*   Use **Zodiac Control** instead of "owner dashboard" when referring to the tool as a product.
*   Use **Zodiac Mini** instead of "Zodiac Telegram App" or just "App".
*   Avoid mixing English and Russian unnecessarily. UI labels should generally be in Russian unless they are proper product names (e.g., `Zodiac Pulse — Аналитика`).
