# Aphrodite Zodiac Priority Launch Plan

**Status:** Dry-run preparation  
**Target:** 13 Zodiac Channels  
**Live Publishing:** Disabled  

## Overview
Aphrodite's first live module will be **Zodiac**. 
This strategic decision prioritizes a highly structured, automated daily content flow before expanding into more complex financial domains.

## Launch Phases
1. **Фаза 1:** Проверка 13 каналов (Audit & config generation).
2. **Фаза 2:** Подготовка 7 дней контента (Baseline backlog).
3. **Фаза 3:** Проверка Telegram Mini App (Web App integration).
4. **Фаза 4:** Подготовка CTA-кнопок.
5. **Фаза 5:** Dry-run публикаций (Simulated dispatch).
6. **Фаза 6:** Ручное разрешение на Live (Strictly gated).

## Future Finance Modules
Following the successful launch of Zodiac, the platform will expand to:
- Валюты (Currency)
- Крипта (Crypto)
- Металлы (Metals)

These modules will utilize a dedicated **RU/UA language channel strategy**.

## Legacy Channels
The old **15-channel network** remains paused and separated from current launch priorities. It will be restarted according to its own roadmap later.

## Safety Notice
At this stage, **NO TELEGRAM API CALLS ARE MADE**. There is no live publishing, no real tokens, and no server state mutations outside of local JSON backups.
