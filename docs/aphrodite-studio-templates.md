# Aphrodite Studio Templates Library

The **Template Library** (`/dashboard/networks/aphrodite/studio/templates`) is a static repository of structure, prompts, and designs for the Aphrodite content factory.

## Overview
It provides pre-defined configurations for content generation across all Telegram-15-Channels modules:
- Каналы Зодиака
- Валюты
- Крипта
- Металлы
- Недвижимость
- Общие каналы

## Categories
1. **Reels / Shorts**: Hooks, scenes, voiceover instructions, and CTAs.
2. **Image Prompts**: Stable Diffusion/Midjourney style prompts tailored to specific module aesthetics (e.g., Mystical Zodiac, Clean Finance, Neon Crypto).
3. **Telegram Captions**: Pre-written templates for text posts with designated placeholders (`{date}`, `{module}`, `{main_value}`, `{cta}`, `{source_note}`).
4. **Covers / Thumbnails**: Concept designs for video and post thumbnails.
5. **Other Content Types**: Carousels, Weekly Digests, Prompt Packs.

## Safety and Operational Rules
- All templates in this library are strictly static and read-only.
- No live content generation APIs (e.g., OpenAI, Midjourney) are connected to the templates page.
- There are no automatic triggers for Telegram publishing.
- The templates are designed to streamline manual prompt generation and review before any content enters the real publishing pipeline.
