# Aphrodite Legacy Channel Content Profiles

This document details the original content profiles of the 15 legacy channels on the Aphrodite Platform.

## 1. Ідеї для бізнесу
* **Категория:** Общие темы
* **Язык:** UA
* **Аудитория:** люди, которые ищут малый бизнес, сервисные идеи, ниши, проверки спроса
* **Контент:** сервисные идеи, маленькие бизнес-гипотезы, проверка спроса, как отличать рабочую идею от фантазии
* **Формат:** короткий практический пост, идея дня, проверка спроса, первый шаг
* **Примеры тем:**
  * Сервисная идея: как пройти проверку спросом
  * Малый бизнес без лишнего риска
  * Идея, которую можно проверить за неделю
