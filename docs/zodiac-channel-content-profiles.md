# Зодиак: Контентные профили 13 каналов

В модуле Зодиак создано 13 контентных профилей (1 общий канал + 12 знаков зодиака). Это базовые шаблоны, которые определяют позиционирование, тон, рубрики, форматы и призывы к действию (CTA) для каждого канала.

## Общая структура (Daily)

Все 13 каналов работают по единой ежедневной сетке контента:
1. Заголовок
2. Энергия дня
3. Любовь
4. Деньги / работа
5. Совет дня
6. Число дня
7. Аффирмация
8. CTA (Mini App / совместимость / подписка)

## Студия и форматы (Studio Integration)

Визуальный контент (картинки для постов, короткие видео) создается через единый модуль Студия.
Основные форматы:
* Картинка (портрет / квадрат) к текстовому посту
* Reels/Shorts (например: "Главная энергия дня")
Все эти материалы заказываются по брифам и рендерятся в Студии.

## 13 профилей

### Общий гороскоп
* Позиционирование: общий ежедневный и недельный гороскоп для всех знаков.
* Тон: информативный, объединяющий, позитивный.

### Огонь (Овен, Лев, Стрелец)
* Тон: прямой, энергичный, вдохновляющий.
* Фокус: решительность, личная сила, движение вперед.

### Земля (Телец, Дева, Козерог)
* Тон: спокойный, практичный, деловой.
* Фокус: стабильность, порядок, эффективность, долгий результат.

### Воздух (Близнецы, Весы, Водолей)
* Тон: лёгкий, дипломатичный, интеллектуальный.
* Фокус: общение, идеи, баланс, нестандартные решения.

### Вода (Рак, Скорпион, Рыбы)
* Тон: поддерживающий, глубокий, мистический.
* Фокус: эмоции, интуиция, трансформация.

## Статус запуска и безопасность
* Состояние: **Подготовка**
* Публикация: **Отключена**
* API вызовы: **Не выполняются**
* Следующий этап: Подготовка контента на первые 7 дней.
