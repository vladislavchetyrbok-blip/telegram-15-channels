# Визуальный апгрейд Матрицы судьбы

Package 201 обновляет пользовательский экран `/birth-matrix`: вместо старого mock-интерфейса теперь виден русский экран «Матрица судьбы» с коротким обещанием, понятной карточкой даты рождения и результатом в компактных смысловых блоках.

## Что изменилось

- Заголовок экрана: `Матрица судьбы`.
- Metadata страницы переведена на русский: `Матрица судьбы`.
- Обещание: `Узнай главные энергии даты рождения и то, что стоит развивать.`
- Ввод даты рождения оставлен через общий текстовый `ZodiacDateInput`.
- Helper сохранён: `Формат: ДД.ММ.ГГГГ. Например: 15.06.1998.`
- Scope сохранён: `birthDateScope="birth-matrix"`.
- Runtime marker сохранён через общий компонент: `data-birth-date-ui="v2-global-1900-today"`.
- Результат разложен на 4 карточки: `Главная энергия`, `Сильная сторона`, `Зона роста`, `Следующий шаг`.
- Подробный блок `Энергии даты` вынесен ниже короткого summary, без длинного полотна текста.
- Будущая полная версия показана только как безопасный teaser без оплаты, без доступа, без записи в базу.

## Границы безопасности

- Native `type="date"` для даты рождения не возвращался.
- Поддержка `15.06.1998`, `15061998`, `1998-06-15`, `01.01.1990`, `31.12.1985`, `1900-01-01` остаётся на общем helper.
- Future dates и даты раньше 1900 отклоняются.
- Без оплаты.
- Без Telegram Stars.
- Без `sendInvoice`, `createInvoiceLink`, `pre_checkout_query`, `successful_payment`.
- Без реальной VIP-разблокировки.
- Без Telegram API.
- Без записи в базу.
- Без изменения схемы базы данных.
- Без workflows, cron, publish scripts и bot sending logic.

## Переход из Mini App

`/miniapp` сохраняет ссылку на `/birth-matrix`. Отдельный Mini App flow «Матрица судьбы» внутри общего zodiac-экрана продолжает использовать общий `ZodiacDateInput` и scope `miniapp-matrix`; Package 201 не меняет его расчётную логику.
