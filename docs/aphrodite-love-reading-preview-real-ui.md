# AI Love Reading — реальный preview UI (Package 149)

## Что это

Package 149 создаёт реальный пользовательский экран бесплатного preview для **AI Love Reading**.
Это превращает hero первого экрана (Package 148) в отдельный безопасный preview-экран по адресу
`/miniapp/love-reading-preview`.

Превью **локальное и детерминированное**. Используется существующая модель
`createAphroditeLoveReadingFoundationPreview` (Package 136) — без вызовов AI.

## Что показывает экран

- Заголовок: **AI Love Reading**.
- Обещание: «Узнай, что между вами происходит, что он может чувствовать и где ваша главная зона риска.»
- Локальный детерминированный preview:
  - Главная энергия связи
  - Сильная сторона
  - Зона риска
  - Следующий шаг
- Блок «Что будет в полном Love Report позже» — только пояснительная / будущая копия (что
  он/она чувствует, почему отдаляется, прогноз на 30 дней, red flags, личный совет). Без разблокировки.
- Видимые границы безопасности (русский текст + английский `data-boundary`-токен для стабильного QA):
  «Нет оплаты», «Нет реальной VIP-разблокировки», «Нет вызова Telegram API»,
  «Нет записи в базу данных», «Только локальный preview».
- CTA без оплаты: «Проверить связь» (→ `/compatibility`), «Вернуться к модулям» (→ `/miniapp`).

## Чего этот пакет НЕ делает

- Не вызывает AI API.
- Не реализует оплату и не показывает активный платёжный CTA.
- Не реализует реальную VIP-разблокировку.
- Не вызывает Telegram API и не создаёт Telegram Stars invoice.
- Не пишет в базу данных.
- Не меняет активную Telegram CTA-логику.
- Не меняет cron / workflow / publish scripts.
- Не запускает продакшн.

Daily / weekly automation остаётся рабочей. Manual Review остаётся UI / read-only.
